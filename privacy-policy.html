Privasi Pengguna

Kebijakan Privasi

Aplikasi: One Keyboard (com.raditzz.onekeyboard)
Terakhir Diperbarui: 11 Oktober 2026

Selamat datang di One Keyboard. Privasi Anda adalah prioritas utama kami. Dokumen Kebijakan Privasi ini menjelaskan bagaimana aplikasi kami menangani data Anda saat menggunakan layanan keyboard dan pemindai kode kami.

Ringkasan Singkat: One Keyboard beroperasi 100% secara offline di perangkat Anda. Kami TIDAK mengumpulkan, TIDAK menyimpan, dan TIDAK pernah mentransmisikan data pengetikan, barcode, riwayat, atau informasi pribadi Anda ke server mana pun di internet.

1. Izin Perangkat & Penggunaannya

Untuk menjalankan fungsi utamanya, One Keyboard memerlukan izin berikut:

  • Kamera (android.permission.CAMERA): Digunakan secara eksklusif untuk menampilkan jendela pemindai dan membaca Barcode atau QR Code langsung ke kolom teks yang sedang aktif. Pemrosesan visual barcode dilakukan secara instan di memori perangkat menggunakan Google ML Kit. Kamera tidak pernah mengambil foto tersembunyi, tidak pernah merekam video, dan tidak pernah menyimpan rekaman gambar ke penyimpanan perangkat.
  • Getar (android.permission.VIBRATE): Digunakan semata-mata untuk memberikan umpan balik taktil (haptic feedback) saat tombol keyboard ditekan atau saat kode berhasil terdeteksi.

2. Tidak Memiliki Izin Internet

Aplikasi One Keyboard secara sengaja tidak meminta izin jaringan/internet (android.permission.INTERNET) dari sistem operasi Android. Hal ini menjamin secara teknis bahwa aplikasi ini tidak memiliki akses maupun kemampuan untuk mengirimkan data pengetikan, isi barcode, clipboard, atau metadata apa pun ke pihak luar atau server cloud.

3. Pengolahan Data Pengetikan & Papan Klip (Clipboard)

Sebagai aplikasi Keyboard (Input Method Editor), segala hal yang Anda ketik dan teks yang Anda simpan di papan klip tetap berada di dalam memori lokal ponsel Anda. One Keyboard tidak menyertakan logger keystroke, analitik perilaku, atau pelacak pengetikan.

4. Layanan Pihak Ketiga & Iklan

Aplikasi ini:

  • Tidak memuat iklan pihak ketiga (Ad-Free).
  • Tidak menggunakan SDK analitik atau pelacak iklan pihak ketiga (seperti Firebase Analytics, Facebook SDK, dll).

5. Privasi Anak-Anak

One Keyboard tidak menargetkan atau secara sengaja mengumpulkan data apa pun dari anak-anak di bawah usia 13 tahun. Karena aplikasi tidak mengumpulkan data pribadi apa pun dari pengguna mana pun, aplikasi ini aman untuk digunakan oleh semua kelompok usia.

6. Perubahan pada Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu seiring dengan pembaruan fitur aplikasi. Setiap perubahan akan dicantumkan secara transparan pada halaman ini dengan tanggal pembaruan terbaru.
